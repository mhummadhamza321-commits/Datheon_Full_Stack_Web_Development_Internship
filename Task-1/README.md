# Muhammad Hamza — Developer Portfolio

A responsive personal developer portfolio built with semantic HTML5, CSS3, and vanilla JavaScript (ES6+). It showcases my background, technical skills, selected projects, CV, and contact information.

## Features

- Mobile-first responsive layout using CSS Grid and Flexbox
- Dark/light theme toggle with saved preference
- Responsive mobile navigation
- Smooth-scrolling section links
- Project showcase with technology tags and project status
- CV download link
- Accessibility features, including a skip link, descriptive button labels, and reduced-motion support
- No build step or framework required

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Git and GitHub
- Vercel for deployment

## Deployment on Vercel

1. Sign in to Vercel.
2. Select **Add New → Project**.
3. Import the GitHub repository containing this portfolio.
4. Select **Other** as the framework preset, if prompted.
5. Leave the build command and output directory empty unless Vercel requires different settings.
6. Deploy the project and test the generated website URL.

Pushes to the connected GitHub branch can trigger automatic deployments.
