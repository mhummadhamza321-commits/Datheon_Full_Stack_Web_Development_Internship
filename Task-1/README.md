# Muhammad Hamza — Developer Portfolio

A responsive personal portfolio built with semantic HTML5, CSS3, and vanilla JavaScript (ES6+). It presents my background, technical skills, selected projects, and contact links.

## Features

- Mobile-first responsive layout using CSS Grid and Flexbox
- Dark/light theme toggle with saved preference
- Responsive mobile navigation
- Smooth-scrolling section links
- Project showcase with technology tags and project status
- CV download link
- Accessible skip link, button labels, and reduced-motion support
- No build step or framework required

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Git and GitHub
- Vercel (deployment)

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deployment on Vercel

1. Push this folder to a public GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the portfolio repository.
4. For this static HTML/CSS/JS project, leave the framework preset as **Other**.
5. Leave the build command and output directory empty unless Vercel prompts otherwise.
6. Deploy, then open the generated URL and test the site.

Every push to the connected GitHub branch can trigger a new deployment.
